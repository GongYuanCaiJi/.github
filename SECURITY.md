# Security Policy

## Supported Versions

Only the latest commit on the default branch is supported. Older commits and tags do not receive security fixes.

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Use GitHub's private vulnerability reporting instead: open the repository's **Security** tab and choose **Report a vulnerability**. You will get a reply there, and fixes are published as a GitHub Security Advisory.

請不要在公開 issue 回報安全漏洞。請到該 repo 的 **Security** 分頁，點 **Report a vulnerability** 私下回報，處理結果會在那裡回覆。
